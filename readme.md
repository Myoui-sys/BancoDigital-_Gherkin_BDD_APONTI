# BancoDigital - Gherkin BDD APONTI

## Descrição
Projeto de testes automatizados utilizando Gherkin e BDD (Behavior-Driven Development) para a aplicação BancoDigital.

## Tecnologias
- Gherkin
- BDD (Behavior-Driven Development)
- Cucumber
- Selenium

## Estrutura do Projeto
```
├── features/
│   ├── *.feature
├── steps/
│   ├── step_definitions.py
├── README.md
└── requirements.txt
```

## Como Executar

### Instalação de Dependências
```bash
pip install -r requirements.txt
```

### Executar os Testes
```bash
cucumber
```

## Cenários de Teste
Os cenários de teste estão descritos em arquivos `.feature` na pasta `features/`.
